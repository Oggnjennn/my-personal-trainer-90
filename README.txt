MY PERSONAL TRAINER 90

SADRŽAJ
- index.html: aplikacija
- manifest.webmanifest: podešavanja instalacije
- sw.js: offline keširanje
- icon-192.png / icon-512.png: ikone

KAKO DA POKRENEŠ
1. Raspakuj ZIP.
2. Postavi sve fajlove u isti folder na HTTPS hosting (npr. GitHub Pages, Netlify ili Vercel).
   PWA instalacija i offline režim zahtevaju HTTPS (ili localhost).
3. Otvori objavljeni HTTPS link u Safari-ju na iPhone-u.
4. Pritisni Share / Deljenje -> Add to Home Screen / Dodaj na početni ekran.
5. Potvrdi Add / Dodaj.

NAPOMENE
- Podaci se čuvaju lokalno u pregledaču na uređaju (localStorage).
- Izvezi JSON rezervnu kopiju u kartici Podešavanja.
- AI trener u ovoj verziji je lokalni savetnik zasnovan na pravilima, nije povezan sa cloud AI modelom.
- Aplikacija ne meri automatski puls, kalorije ili korake.
- Plan je početni okvir i treba ga prilagoditi stvarnoj kondiciji, tehnici i eventualnim zdravstvenim ograničenjima.
